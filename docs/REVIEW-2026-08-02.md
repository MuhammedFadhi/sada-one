## Two further bugs found and fixed during the review

**"Last Login" always said Never.** The auth store built the `last_login_at` update but never
awaited it. A Supabase query builder is lazy — it only issues the HTTP request when awaited or
`.then()`-ed, so the update was never sent for anyone. That matters right now: with 45 people
about to receive credentials, this field is how you see who has actually activated. Fixed.

**Managers saw an empty Suggestions page.** The RLS policy grants suggestion visibility to
`hr_officer` and `admin` only; the new UI treated managers as management too, so a manager saw
the "shows who submitted" notice above an empty list. The UI now mirrors the policy exactly.
Managers are deliberately excluded — suggestions frequently concern managers.
